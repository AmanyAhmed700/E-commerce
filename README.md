# Full-Stack E-Commerce Web App 🚀

Excited to share my latest project: a Full-Stack E-Commerce Web App!  
I built a full-stack E-Commerce application using the MERN Stack (MongoDB, Express.js, React.js, Node.js) with a comprehensive Admin Dashboard.

---

## 🔹 User Features

- Secure login and registration with JWT authentication.
- Browse products and add them to the cart.
- Checkout with multiple payment options (Cash / Card).
- Manage cart items and update quantities in real-time.

---

## 🔹 Admin Features

- Product management (Add / Edit / Delete).
- View users along with their associated orders.
- Live statistics: total users, products, and orders.

---

## 🔹 Tech Stack

- **Frontend:** React + Tailwind CSS  
- **Backend:** Node.js + Express  
- **Database:** MongoDB  
- **Authentication:** JWT + Role-based Access Control

---

## 📌 Project Structure

### Backend
- `models/` - Database schemas
- `controllers/` - Request handlers
- `routes/` - API endpoints
- `middleware/` - Auth, error handling
- `utils/` - Helper functions
- `config/` - DB and environment configs
- `server.js` - Entry point

### Frontend
- `src/components/` - Reusable UI components
- `src/context/` - Context API for state management
- `src/pages/` - Pages & routing
- `src/admin-dashboard/` - Admin panel components
- `public/` - Static assets
- `build/` - Production build
- `package.json` - Project dependencies
- `tsconfig.json` - TypeScript config

### Root
- `ecommerce.postman_collection.json` - Postman API collection
- `LICENSE` - License file
- `.gitignore` - Git ignore config
